# learn_algorithm

Practice common algorithms and data structures in Python.

## Sorting Algorithms
- **Bubble Sort** (`sorting/bubble_sort.py`) — O(n²)
- **Selection Sort** (`sorting/selection_sort.py`) — O(n²)
- **Insertion Sort** (`sorting/insertion_sort.py`) — O(n²)
- **Merge Sort** (`sorting/merge_sort.py`) — O(n log n)
- **Quick Sort** (`sorting/quick_sort.py`) — O(n log n) average

## Searching Algorithms
- **Linear Search** (`searching/linear_search.py`) — O(n)
- **Binary Search** (`searching/binary_search.py`) — O(log n), requires sorted input

## Data Structures
- **Linked List** (`data_structures/linked_list.py`) — append, prepend, delete
- **Stack** (`data_structures/stack.py`) — push, pop, peek
- **Queue** (`data_structures/queue.py`) — enqueue, dequeue, peek
